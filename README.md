# Personal Budget Tracker

## Overview

Personal Budget Tracker is a full-stack web application that helps users manage their income and expenses efficiently. Users can add, edit, delete, and view financial transactions while monitoring their financial status through a dashboard and pie chart visualization.

## Features

* Add Income and Expense Transactions
* Edit Existing Transactions
* Delete Transactions
* View All Transactions
* Dashboard Summary
* Total Income Calculation
* Total Expense Calculation
* Balance Calculation
* Pie Chart Visualization using Chart.js
* Smart Budget Advisor
* Responsive UI using Bootstrap
* Data Persistence using MySQL

## Technology Stack

### Backend

* Java 21
* Spring Boot
* Spring Data JPA

### Frontend

* JSP
* Bootstrap 5
* Chart.js

### Database

* MySQL

## Setup Instructions

1. Clone the repository
2. Open the project in Eclipse
3. Create a MySQL database named:

budget_tracker

4. Update database credentials in:

application.properties

5. Run the application

6. Open:

http://localhost:8080
